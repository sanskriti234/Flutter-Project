Put your royalty-free images in this folder using EXACTLY these file names (JPG):

  hero.jpg              - large campus / engineering education background (wide image, 1600px or more)
  campus.jpg            - campus infrastructure / building
  labs.jpg              - engineering laboratories
  library.jpg           - library
  student_activities.jpg- student activities
  classrooms.jpg        - classrooms
  computer_lab.jpg      - computer laboratory
  facilities.jpg        - campus facilities

instead of a broken-image icon, so the site always runs without them.
